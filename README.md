
# 🏠 Roomify - Ứng dụng tìm phòng trọ

Roomify là ứng dụng di động đa nền tảng (Android & iOS) được xây dựng bằng **React Native**, giúp người dùng tìm kiếm, đăng bài và quản lý thông tin phòng trọ một cách thuận tiện. Dự án thuộc đồ án tốt nghiệp [SU25_DATN], hướng đến việc giải quyết nhu cầu tìm phòng trọ nhanh chóng và hiệu quả.

## 🚀 Tính năng chính

- 🔍 Tìm kiếm phòng trọ theo vị trí, giá, tiện nghi,...
- 🏘️ Xem chi tiết thông tin phòng, hình ảnh, liên hệ chủ trọ
- 📝 Đăng bài cho thuê phòng
- 📂 Quản lý tin đã đăng, chỉnh sửa/xóa
- ❤️ Lưu phòng yêu thích
- 🔐 Đăng ký / Đăng nhập người dùng
- 🗺️ Hiển thị phòng trọ trên bản đồ (tùy chọn)
- 🔔 Nhận thông báo khi có phòng phù hợp

## 🛠️ Công nghệ sử dụng

- ⚛️ React Native + Expo
- 🔁 Redux Toolkit (State Management)
- 🔗 Axios (Gọi API)
- 🧭 React Navigation
- 🔐 Firebase Authentication (Xác thực người dùng)
- ☁️ Firebase/Express.js (Server/API)
- 🧪 React Native Testing Library (Testing - tùy chọn)

## ▶️ Cách chạy project

### 1. Clone dự án
```bash
git clone https://github.com/qquan2108/Roomify.git
cd Roomify
```

### 2. Cài đặt dependencies
```bash
npm install
# hoặc
yarn install
```

### 3. Chạy project bằng Expo
```bash
npx expo start
```

> ⚠️ Yêu cầu cài đặt [Expo Go](https://expo.dev/client) trên điện thoại để quét QR và test ứng dụng.
